# ロードマップ（将来案・未実装）

以下は**予定確定ではなく、利用者が希望する機能の候補**です。

| 案 | 説明 | 状態 |
|---|---|---|
| v1.x：更新パッチ | バックアップ付きオフライン更新と復元 | **実装済み（Windows実機未検証）** |
| 表示範囲の拡張 | 選択した複数の図形の寸法変更 | 未実装 |
| 個別の辺位置指定 | 左辺・右辺・上辺・下辺の座標を直接指定 | 未実装 |
| 角丸外形 | R指定で角丸基板を変更 | 未実装 |
| 円弧・切り欠き | 複雑な輪郭の編集 | 未実装 |
| 寸法線クリック編集 | Fusionのスマート寸法に近い、キャンバスからの直接操作 | **未実装** |
| パラメトリック拘束 | 寸法変更に対し図形を整合的に追従 | **未実装** |
| KiCad IPC API版 | SWIG終了後のKiCadにも対応する新プラグイン | 未実装 |
| PCM配布 | KiCad公式/外部PCMへのパッケージ登録 | 未実装 |

必要な機能はIssueで提案してください。寸法変更の期待動作（固定点、どの線が動くか、複数外形の扱いなど）を図や文章で添えてください。
