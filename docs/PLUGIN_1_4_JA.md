# 標準KiCad用プラグイン v1.4.0（試験版）

専用のKiCad本体を使わず、通常のKiCad 10に追加するPython Action Pluginです。C++版の機能をプラグイン用に実装し直しています。KiCad 11以降は対象外です。

## 簡単な導入

1. GitHubの **v1.4.0 試験版Release** から `KiCad10_SmartBoardDimension_v1.4.0_PCM.zip` をダウンロードします。ZIPは展開しません。
2. KiCadマネージャーの「プラグイン＆コンテンツマネージャー」を開き、「ファイルからインストール」でZIPを選びます。
3. PCBエディタを開き直します。起動後に寸法編集用のイベント処理を自動登録します。

公式のPCM一覧への登録申請は行っていません。以前のPython版を手動導入している場合は、同じプラグインを二重に入れないよう、以前の版を外してからPCM版に切り替えてください。ネイティブ版の専用アプリは別製品で、通常のKiCadへこのプラグインを追加する必要があります。

Windowsの従来方式では、別途 `..._Windows.zip` を展開して `Windows_インストール.bat` を使えます。PCM版と重複して導入しないでください。PCM版の更新・削除はPCMで行ってください。

## PCB上で編集

- `Edge.Cuts`に円1個、軸に平行な長方形1個、または閉じた長方形を構成する直線4本を置きます。
- 円の半径は標準の半径寸法で「中心→円周」を指定します。直径は標準の整列寸法で「中心を挟んだ円周の2点」を指定します。長方形は隣り合う角に整列・直交寸法を置きます。
- Escで配置ツールを終了し、寸法をクリックすると数値入力を要求する実装です。選択してE、またはダブルクリックでも要求します。`2*15`、`1in+5mm`などを入力して確定します。
- 円は中心固定、標準寸法による長方形の幅は左辺固定、高さは上辺固定です。接続する他の寸法端点も追従します。部品・配線・ゾーンは動かしません。
- 自動登録に失敗した場合は「ツール→外部プラグイン→スマート基板寸法（PCB上で編集）」を一度起動します。

文字だけを独立して判定するネイティブ版とは異なり、KiCadの選択結果を利用します。寸法線をクリックしても入力が開く場合があり、選択済みの寸法が残っている場合も影響を受けます。標準スナップで端点を合わせてください。円の接続判定の許容差は最大0.01 mm、長方形は角との座標一致が必要です。

## 検証と制約

2026-10-30の作業では利用者の指定により、KiCad本体の起動・操作・実APIアクセス・導入を行っていません。円と長方形の計算・寸法追従・不正値・ロック・座標上限を模擬テストで検証しました。**v1.4.0のクリック操作、自動登録、Undo/Redo、PCMでの実際の導入は実機未確認です。** 試験用の基板コピーで確認してください。

変更はKiCadのAction Pluginメニューを経由させます。タイマーはイベント登録のみを行い、勝手に外形や寸法を作成・変更・保存しません。ファイルの自動保存もしません。

自動テスト44件が成功し、PCMメタデータはKiCad 10.0.7公式ソースのv2スキーマで検証済みです。これらはGUI実機確認の代わりにはなりません。

円弧、穴、複数外形、斜めの長方形、拘束ソルバーは対象外です。入力は0.01～1000 mm。変更対象の外形または寸法がロックされている場合、範囲外になる場合は変更前に拒否します。

SWIGはKiCad 10では利用できますが非推奨APIです。今後のIPC APIへの移行と実機確認は別途必要です。操作感はSolidCraftを参考にした独自実装で、SolidCraftのコードや画像は使用していません。
