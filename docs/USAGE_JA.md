# 操作ガイド（日本語）

このページはPythonプラグイン版です。外部プラグインを起動しないネイティブ版の開発状況と操作は [native/README.md](https://github.com/conmmitmentman/KiCad-SmartBoardDimension/blob/main/native/README.md) を参照してください。

## PCB上で寸法を編集する（v1.3.0開発版）

1. PCBを開き、外部プラグインの「スマート基板寸法」を起動します。
2. PCB上に表示された幅・高さの数字をクリックします。
3. 数値または `2*35` などの計算式を入力し、Enterで確定します。
4. 固定点は小さな編集バーで選びます。「詳細・更新」から以下の補助画面を開けます。

このPython版はPCBを開くたびに起動が必要です。数字クリックによる幅変更はKiCad 10.0.7で確認しました。高さの画面操作、Undo/Redo、再起動後の操作は引き続き検証対象です。

## 準備

KiCad 10のPCBエディタで基板を開き、`.kicad_pcb` のコピーを別名で保存してください。Edge.Cutsには次のどちらかのみ配置できます。

- **長方形1個**：長方形ツールで作った、座標軸と平行な長方形
- **線分4本**：隙間がなく、水平2本・垂直2本で閉じた長方形

Edge.Cutsが空であれば、指定サイズの長方形を新規作成できます。

## 詳細画面での寸法の変更

1. 「ツール → 外部プラグイン → スマート基板寸法（幅・高さ）」を選択
2. 編集バーの「詳細・更新」を開き、図の上のW欄・右のH欄に基板の幅と高さをmmで入力
3. **左上を固定・中心を固定・右下を固定**から基準を選択
4. X/Y座標を必要に応じて入力
5. 変更前の破線と変更後の緑の外形を確認し、「基板に反映」
6. 基板を保存し、DRC（設計ルールチェック）を実行

## 図を使った操作

- **寸法の入力**：W/H欄をクリックすると選択されます。数式・単位も入力できます。Tabで次の欄へ移動できます。W欄でEnterを押すとH欄へ、H欄では反映ボタンへ移動します。
- **ドラッグ**：辺の中央の□をドラッグすると0.1 mm刻みで幅または高さが変わります。中心固定では両側が対称に、右下固定では左辺・上辺が動きます。直接入力には0.1 mmへの丸めはありません。
- **ドラッグを取り消す**：ドラッグ中にEsc。入力していた数式も復元します。
- **固定点**：図の○または右側の選択欄を使用します。選択時のプレビュー形状を維持し、その後の寸法変更に新しい固定点を使います。
- **最初の寸法に戻す**：画面を開いた時点のサイズと位置に戻します。
- **入力エラー**：理由を赤字で表示し、反映ボタンを無効化します。図には最後に有効だった形状が残ります。
- **キャンセル**：ダイアログ内の変更を破棄します。プレビュー中は実際の基板を変更しません。

図は外形の概略プレビューです。部品・配線は表示しません。元の外形と変更後の外形が収まるよう同じ縮尺で表示します。極端に細い外形ではハンドルが重なるため、W/H欄と固定点の選択欄を使ってください。

## 基準点の意味

サイズを入力する前に基準点を選択した場合の例です。例えば元の基板が左上 `(100,100)`、幅40mm、高さ30mmなら中心は `(120,115)`、右下は `(140,130)` です。

| 変更方法 | W=60, H=45 のときの新しい左上 | 新しい右下 |
|---|---|---|
| 左上固定 | (100,100) | (160,145) |
| 中心固定 | (90,92.5) | (150,137.5) |
| 右下固定 | (80,85) | (140,130) |

※座標の数字はmmです。中心固定は内部座標に合わせて極小の丸めが生じる場合があります。

## 数式入力

| 入力 | 計算結果 |
|---|---|
| `20+5` | 25 mm |
| `2*15` | 30 mm |
| `1in+5mm` | 30.4 mm |
| `100mil` | 2.54 mm |
| `2.54cm` | 25.4 mm |

使える演算は `+` `-` `*` `/` `()` のみです。単位を省略した場合はmmとして解釈されます。W/Hは0.01〜2000 mm、基準点および変更後の四隅の座標は±2000 mm以内です。KiCadの内部整数座標でオーバーフローしない範囲に制限しています。

## 編集されるもの / されないもの

**編集**：Edge.Cuts上の許可された長方形外形の座標（新規の場合は矩形を作成）。

**非編集**：部品、配線、パッド、ゾーン、銅箔、シルク、寸法注記。外形のサイズを変えた結果、配置済み部品等が外形からはみ出る場合があります。設計全体が自動追従する「Fusionのパラメトリック拘束」とは異なります。

## 対応しないケース

円弧・角丸・斜め・切り欠き・内側穴・複数外形、線が閉じていない長方形。安全のため変更を中止します。別のEdge.Cuts図形を追加した状態での実行も対象外です。
