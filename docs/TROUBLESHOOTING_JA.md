# トラブルシューティング

| 状況 | 原因と対処 |
|---|---|
| バッチを開くとファイルがない | ZIPの中から直接実行していないか確認。すべて展開して、`scripts/` と `smart_board_dimension/` が隣にある状態で実行。 |
| 「既存のプラグインがありません」 | 初回は更新ではなく `Windows_インストール.bat` を使用。 |
| 「複数のインストール先」 | 古いコピーが別の場所にある可能性。配置先を確認し、PowerShellの `-Destination` で一箇所を明示。 |
| メニューにプラグインが出ない | PCBエディタ再起動。配置先が `.../plugins/smart_board_dimension/__init__.py` か確認。KiCad 10か確認。 |
| インポート時のエラー | KiCadのPythonコンソール等にある `pcbnew.PLUGIN_DIRECTORIES_SEARCH` とエラー内容を確認。`wx` / `pcbnew` がない通常のPythonから実行しない。 |
| 「Edge.Cutsに線・矩形以外」 | Edge.Cutsに他の図形や文字が混じっていないか確認。複雑な形状は非対応。 |
| 「角丸長方形は編集できません」 | v1.xは角丸に非対応。単純な長方形で使用。 |
| ボード外へ部品が出る | 本プラグインは外形のみ変更します。部品・配線を確認しDRCを実行。 |
| 更新しても古い版が動く | PCBエディタを完全に閉じて再起動。KiCadが別フォルダのコピーを優先していないか確認。 |
| バッチが実行できない | Windowsセキュリティ設定や組織ポリシーを確認。許可された手動コピー手順を利用。 |
| ドキュメントにファイルを作れない | v1.2.1は新規導入時に `%APPDATA%\kicad\10.0\scripting\plugins` へ切り替えます。手動配置でもこの探索先を使用できます。 |
| プレビューや注意書きが見えない | v1.2.0の固定ウィンドウサイズによる表示崩れです。v1.2.1へ更新してPCBエディターを再起動してください。 |
| 座標の上限エラー | 幅・高さは0.01〜2000 mm、変更後の四隅は±2000 mm以内です。基準点からはみ出す場合も拒否します。 |
| 更新確認でHTTP 404 | 正式Release・配布アセットが未公開、または更新元URLが違います。寸法編集は引き続き使用できます。 |
| 前の版に戻せない | 事前バックアップがない/パスが違う可能性。`%LOCALAPPDATA%\SmartBoardDimension\backups` を確認。 |

## 不具合報告時に必要な情報

KiCadの版（例10.0.x）、OS、エラー全文、`Edge.Cuts` の形状が「長方形1個」か「線分4本」か、操作手順、更新前後の版を記載してください。公開前に回路データ・氏名・機密ファイル名などを取り除いてください。

検証した環境・範囲は [実機検証記録](VALIDATION_JA.md) を参照してください。
