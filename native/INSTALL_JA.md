# 初回だけ設定し、次回からアイコンで起動する

Source v1.0.2で、**ビルド済みのネイティブ版**を登録する初回設定を追加しました。初回の本体ビルドを自動で代行するものではありません。コンパイル済みの一般向けWindowsパッケージは未公開です。

## 初回設定

1. Source v1.0.2のZIP全体を展開します。
2. `native/初回設定.cmd` をダブルクリックします。
3. 「ビルド先を選ぶ」で `build/msvc-win64-release` など、ネイティブ版のビルドフォルダーを選びます。
4. 「設定済み」を確認します。デスクトップとスタートメニューに「スマート基板寸法（ビルド版）」ができます。

必要な出力ファイルと、寸法機能に固有の文字列がPCB用バイナリに含まれるかを検査します。通常版・パッチ適用前・必要ファイルが不足したビルドは登録できません。この判定は機能の識別であり、デジタル署名や実行時の動作保証ではありません。

## 2回目以降

専用アイコンから「新しい基板を開く」「保存済みの基板を開く」「円のサンプルを試す」を選びます。再起動しても登録先を記憶します。同じ版を使う間は、毎回のコマンド入力・再ビルド・再設定は不要です。

初回設定は起動スクリプトとサンプル原本を `%LOCALAPPDATA%/SmartBoardDimension/build-launcher` にコピーします。元のSource ZIPの展開先には依存しません。アプリ本体はコピーせず、**登録したビルドフォルダーをそのまま使うため、そのフォルダーは残してください。**

設定は `%LOCALAPPDATA%/SmartBoardDimension/native-1.0`、編集用サンプルは `%LOCALAPPDATA%/SmartBoardDimension/samples` に保持します。初回設定をやり直しても既存の設定と編集済みサンプルは上書きしません。設定画面を開いただけでPCBを変更・保存することもありません。

ビルド先を移動した場合や新しい版へ切り替える場合は、起動画面の「ビルド先を選ぶ・選び直す」で再登録します。本体の自動更新はありません。

## 困ったとき

| 表示・状態 | 対処 |
| --- | --- |
| 初回設定.cmdがない | 古いSource ZIPではなく、Source v1.0.2を取得し、ZIP全体を展開してください。 |
| 必要ファイルがない | exeファイルやソースのルートではなく、コンパイルが完了したビルドフォルダーを選びます。 |
| 寸法機能が見つからない | ネイティブ版のパッチを適用して本体をビルドし直してください。通常版のKiCadでは登録できません。 |
| 保存したビルド先が見つからない | 「ビルド先を選ぶ・選び直す」で新しい場所を登録します。 |
| ショートカットを消してしまった | Source ZIPの初回設定.cmdをもう一度開き、同じビルド先を登録します。 |
| Source ZIPだけで導入したい | 現在は本体ビルドが必要です。一般向けWindowsパッケージの公開はまだです。 |

起動ショートカットはそのPowerShellプロセスだけでスクリプトを実行する指定を使います。Windows全体の実行ポリシーや、通常版KiCadの実行ファイル・ファイルの関連付けは変更しません。
