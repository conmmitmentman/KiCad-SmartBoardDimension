# ネイティブ版の簡単導入（準備中）

2026-10-30時点で、一般向けWindowsバイナリは未公開です。公開済みSource ZIPは開発者向けです。

## 実装済みの導入方式

配布フォルダーのInstall.exeから管理者権限なしで導入し、デスクトップ／スタートメニューの「スマート基板寸法（ネイティブ版）」から起動します。日本語の画面で「基板ファイルを開く」「円のサンプルで試す」を選びます。

- **新しい基板を作る**：空のPCBエディタを開きます。保存するときに名前を付けます。
- **基板ファイルを開く**：保存済みの `.kicad_pcb` を選びます。まだ存在しないファイル名は指定できません。
- **円のサンプルで試す**：サンプルの寸法数字をクリックして、例えば `2*15` を入力しEnterで確定します。Ctrl+Zで元に戻せます。

通常のKiCadとは別フォルダー・別設定を使用します。初回設定は日本語。既存の言語設定は上書きしません。導入先とバージョンを起動画面に表示します。配布ファイルはSHA256で検査し、途中コピーの状態を完成版として扱いません。

標準位置にKiCad 10がある場合は、その標準ライブラリを自動参照します。ない場合は空のライブラリ一覧で始められます（部品ライブラリそのものは同梱していません）。初回にKiCadの更新通知・利用状況送信の選択画面が出た場合は、表示に従って希望する設定を選んでください。

## 入っているか確認するには

デスクトップまたはスタートメニューの **スマート基板寸法（ネイティブ版）** を開きます。起動画面に「導入済み / 日本語対応」と導入先が表示されれば、専用アプリから起動しています。通常の「KiCad」アイコンは公式版を開きます。

導入先は `%LOCALAPPDATA%\Programs\SmartBoardDimension`、専用の設定・サンプルは `%LOCALAPPDATA%\SmartBoardDimension` です。更新時も既存設定と編集済みサンプルを保持します。

- native/windows/Launcher.cs：日本語の導入・起動画面、ユーザー別インストール、専用ショートカット、設定分離。
- tools/build_native_windows.py：検証済みWindowsビルドからDLL/Python/翻訳/ライセンスをまとめる開発者向けツール。
- 2026-10-29：ローカルWindowsでパッケージ生成、ユーザー別インストール、専用ショートカット作成に成功。パッケージ内の実行環境だけをPATHに指定し、日本語の起動画面・PCBエディタのメニュー表示を実画面で確認。
- ランチャーの検査：正常ファイルの受理、改変・空一覧・範囲外パス・不正一覧の拒否、日本語初期設定、既存設定の保持、標準ライブラリ検出に成功。`windows/test_launcher.ps1` で、実際のインストールや設定を変更せず再検証できます。
- 起動画面には「導入済み」と「展開フォルダーから起動」を区別して表示。円サンプルの寸法文字も画面に収まりやすい位置へ調整。
- 2026-10-30：導入済みアプリで円の半径28 mmに `2*15` を入力し、半径30 mm・直径60 mmへの更新とUndo/Redoを確認。初期ライブラリの手動選択は不要でした。
- 再インストールで破損した導入ファイルを修復可能にしました。以前の導入先は `.before-repair-...` フォルダーへ保存し、交換に失敗した場合は復元します。専用設定と編集済みサンプルは置換対象外です。
- wxWidgets標準ダイアログ用の日本語カタログも配布対象に追加しました。
- 任意のIPC/Pythonプラグイン機能は今回の動作保証範囲外です。既存の設定に開発環境のPythonパスが残っている場合があり、その機能を含む完全な別PC検証は未完了です。
- 公開前に、開発環境のないWindowsでの導入試験、依存ファイル・対応ソースとライセンス同梱の確認、配布ZIPと公開処理を完成させる必要があります。
