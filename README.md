# スマート基板寸法 — ネイティブ版

**日本語** · [English](README.en.md)

KiCad 10.0.7のPCBエディタ上で寸法の数字をクリックし、長方形の幅・高さや円の半径・直径を数値や計算式で変更できます。寸法の計算とWindowsランチャーはRustで実装し、PCBの画面操作とUndoはKiCadのC++に接続しています。

## 最初の導入

現在の配布物はソースZIPです。初めて使う場合は、寸法機能を含むPCBエディタとランチャーのビルドが必要です。

1. [最新版のRelease](https://github.com/conmmitmentman/KiCad-SmartBoardDimension/releases/latest)の「Assets」から `KiCad10_NativeDrivingDimension_Source_v…zip` を取得し、ZIP全体を展開します。
2. [WindowsでのRust版ビルド手順](native/RUST_MIGRATION_JA.md)に沿って、PCBエディタとランチャーを用意します。
3. `target\release\smartboard-launcher.exe` を開き、「ネイティブ版のビルド先を登録／変更」でビルドフォルダーを選びます。ビルド済みであれば、この登録から始められます。

## 次回からは専用アイコンで起動

デスクトップまたはスタートメニューの **「スマート基板寸法（ネイティブ版）」** を開きます。新規基板、保存済みの基板、円のサンプルを選べます。

登録したビルド先はPCを再起動しても保存されます。普段の起動はアイコンだけで済みます。ビルドフォルダーは残してください。別のフォルダーに移したり、新しい版を別の場所にビルドしたりしたときは、ランチャーでその場所を登録します。

## 日本語と英語の切り替え

- **起動画面**は、右上の **English** または **日本語** を押して切り替えます。選択は次回も引き継ぎます。
- **PCB画面**は、KiCadの設定メニュー（**Preferences → Set Language**）で **日本語** または **English** を選びます。寸法入力欄とエラーメッセージはPCB画面の言語に合わせます。
- 初めてPCBエディタを起動すると、起動画面の言語でPCB側の初期設定を作ります。設定済みの場合は、PCB側の言語メニューで切り替えます。

## 寸法を変えるには

1. `Edge.Cuts`の円・長方形に標準の寸法を配置します。
2. 配置を終えて、寸法の**数字**をクリックします。
3. `30`、`2*15`、`1in+5mm`などを入力し、Enterで確定します。Escで取消、Ctrl+Zで元に戻します。

円のサンプルでは、半径の数字へ `2*15` を入力すると半径30 mm・直径60 mmになります。部品や配線は移動しません。
