# スマート基板寸法 — ネイティブ版

PCB上の寸法の数字をクリックして、長方形の幅・高さや円の半径・直径を、数値・計算式で変更できます。KiCad 10.0.7に機能を追加した非公式のPCBエディタです。

## 最初の導入

**現在の公開物はソース版です。初回はネイティブ版のビルドが必要です。** ZIPだけで使えるコンパイル済みアプリ・一般向けインストーラーは未公開です。

| 今の状態 | 次にすること |
| --- | --- |
| 専用のネイティブ版アイコンから使えている | そのアイコンで起動できます。設定をやり直す必要はありません。 |
| ネイティブ版をビルド済み | 下の「初回設定」を1回だけ行います。 |
| まだビルドしていない | [Windowsビルド手順](native/BUILD_WINDOWS_JA.md)で本体を用意してから、初回設定へ進みます。 |

### ビルド済みなら、初回設定は3ステップ

1. [Source v1.0.1のRelease](https://github.com/conmmitmentman/KiCad-SmartBoardDimension/releases/tag/native-source-v1.0.1)から **`KiCad10_NativeDrivingDimension_Source_v1.0.1.zip`** をダウンロードし、**ZIP全体を展開**します。
2. 展開先の **`native/初回設定.cmd`** をダブルクリックし、「ビルド先を選ぶ」でネイティブ版のビルドフォルダーを選びます。例：`C:\dev\kicad\build\msvc-win64-release`。
3. 「設定済み」と表示されたら完了です。「円のサンプルを試す」または「保存済みの基板を開く」を選びます。

ビルド先の入力・コマンド実行・管理者権限は不要です。通常版KiCadのインストール先ではなく、寸法機能を含めてビルドしたフォルダーを選んでください。

## 次回からは専用アイコンだけ

デスクトップまたはスタートメニューの **「スマート基板寸法（ビルド版）」** を開きます。

- **新しい基板を開く**：空のPCBエディタを起動します。
- **保存済みの基板を開く**：基板ファイルを選んで起動します。
- **円のサンプルを試す**：寸法編集を試せます。編集済みのサンプルは上書きしません。

**同じビルドを使う間は、PCを再起動しても再ビルド・パス入力・初回設定は不要です。** 設定と起動用ファイルをユーザー用フォルダーへ保存します。展開したSource ZIPのフォルダーは起動に不要になりますが、**選んだビルドフォルダーは移動・削除せず残してください。**

ビルド先を移動した場合や、新しい版を別の場所へビルドした場合だけ、起動画面の「ビルド先を選ぶ・選び直す」で登録し直します。機能の更新には、その版の本体ビルドが必要です。初回設定を繰り返しても、専用の設定と編集済みサンプルは保持します。

## 寸法を変えるには

1. `Edge.Cuts`の円・長方形に標準の寸法を配置します。
2. 配置を終えて、寸法の**数字**をクリックします。
3. `30`、`2*15`、`1in+5mm`などを入力し、Enterで確定します。Escで取消、Ctrl+Zで元に戻します。

円のサンプルでは、半径の数字へ `2*15` を入力すると半径30 mm・直径60 mmになります。部品や配線は移動しません。
